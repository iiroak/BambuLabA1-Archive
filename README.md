# BambuLabA1-Archive

Mi archivo personal de diseños 3D, modificaciones, perfiles de impresión,
configuraciones y pruebas con la **Bambu Lab A1**. Lo guardo aquí para tenerlo
ordenado y compartir lo que pueda servirle a alguien más.

## Organización del archivo

```text
Designs/
  A1-Modifications/
    Cable-Chains/   Cadenas y soportes para el cableado
    AMS-Lite/       Conectores y protección del hub
    Tools/          Accesorios de mantenimiento
  Storage/          Cajas, tapas y organizadores
PrintPlates/        Proyectos agrupados y archivos ya laminados
Profiles/           Ajustes de proceso, filamento e impresora
Scripts/            Herramientas para generar o modificar archivos
Docs/               Convenciones y registro de pruebas
Templates/          Plantillas para añadir proyectos
```

Cada ficha incluye sus archivos, medidas o notas de compatibilidad, perfiles
guardados y autoría. Los modelos originales conservan sus metadatos. Los JSON
marcados como snapshot son registros de ajustes, no presets importables.
