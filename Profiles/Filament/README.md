# Ajustes de filamento

El primer proyecto utiliza el preset **Bambu PLA Basic @BBL A1**, incorporado
en su 3MF. Aquí se añadirán exportaciones y variantes propias de materiales.

Registra material, fabricante, boquilla y resultado de las pruebas junto a
cada perfil para distinguir ajustes verificados de ajustes por probar.
