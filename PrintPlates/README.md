# Placas de impresión

Proyectos agrupados para preparar varias piezas en una misma placa.

- [StackBox: dos recipientes y dos tapas en placas separadas](StackBox-Height3x-Height6x/).

Cada conjunto indica impresora, boquilla, material, tipo de placa y ajustes
incluidos. Los archivos `.gcode.3mf` contienen el laminado listo; `Projects/`
conserva los proyectos editables.
