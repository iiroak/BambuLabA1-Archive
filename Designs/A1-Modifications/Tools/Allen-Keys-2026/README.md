Mangos para las llaves Allen del kit nuevo de la A1 2026, seleccionados por el mantenedor. El nombre original del diseño menciona Snapmaker U1.

## Llaves del kit 2026

El mantenedor identifica este diseño para las llaves Allen incluidas en la
versión nueva de la A1 2026. El título original es **SNAPMAKER U1 allen keys handle**.
Se conserva el nombre del archivo para reconocer su procedencia.

El proyecto guarda una **pausa a Z = 4,8 mm** (`M400 U1`) para insertar la
llave metálica dentro del mango y continuar la impresión. El archivo
`Metadata/custom_gcode_per_layer.xml` se conserva íntegro.

El perfil de impresora guardado en este archivo es **Bambu Lab A2L** y el
material es **Generic PETG**; la tabla recoge esos ajustes de origen.

Los modelos se archivan como proyectos 3MF editables, con sus ajustes y datos
de impresión. La compatibilidad física de estas mejoras con cada unidad
de impresora permanece sin probar en este archivo.
